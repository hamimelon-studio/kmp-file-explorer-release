Google Play Console

All files access (MANAGE_EXTERNAL_STORAGE) declaration

Core useFile management (file manager)
Melon is a file manager. Its core function is to let the user browse, open, copy, move, rename, zip and delete any file in shared storage, and to back up the user's photos and chosen folders to the user's own NAS (network storage). Folders the user chooses include ones outside MediaStore collections (Download, Documents, app export folders, folders created by other apps), which the Storage Access Framework cannot cover for whole-device browsing and multi-folder backup. Files are only ever accessed in response to the user's navigation or the backup folders they selected, and are never uploaded to our servers.

Demo video for this declaration (30–60 s, recorded separately): open Melon → grant All files access from the in-app prompt → browse Download and a non-media folder → copy a file → open Backup, set up "Back up to my NAS" and start the backup (the status card shows files going to the NAS).

App Store Connect

Export compliance — answer to confirm

Melon uses standard encryption beyond what iOS provides (AES-256-GCM for .melontxt files and pairing keys, TLS between the user's devices). Recommended answer: "Uses non-exempt encryption: Yes", then claim the mass-market exemption (standard algorithms protecting the user's own data). App Store Connect then asks whether a French encryption declaration is needed for distribution in France. After the first approval, Apple issues an export-compliance code; adding it to the app's Info.plist stops later uploads asking again.

App Review notes

Melon backs up the user's photos and videos straight to their own NAS (a network drive at home, over SMB or WebDAV) and is a full file manager. No account is needed. Backup needs the user's own NAS on the same Wi-Fi, so it cannot be completed without one; we cannot provide a NAS reachable from Apple. The attached video shows the whole flow on an iPhone: Backup > Back up to my NAS > pick the NAS, the folder and the layout > the status card counting photos as they arrive on the NAS. Without a NAS you can still review: the setup screens up to the NAS address, the file manager, the photo and video viewers, the photo catalogue map and timeline, and "Share via link" (open the link it shows in a browser on the same network). Local network: Melon talks to the user's own NAS, devices and browsers on the same Wi-Fi. Its built-in web server is started by the user, is reachable only on the local network, and serves only the files the user shares; share links expire after 30 minutes. No downloaded or executable code: the app ships with two built-in plugins compiled into the binary and loads no others. Camera: used only to scan pairing QR codes.

Remaining steps

  1. Publish this repository (push) so the privacy policy and support links work.
  2. Google Play upload key: create one keystore, keep it out of every repository and back it up (losing it means a key-reset request to Google). Build a signed app bundle; Play App Signing holds the real app key.
  3. Google Play closed test: new personal developer accounts must run a closed test with at least 12 testers for 14 days before production access.
  4. Upload the preview video to YouTube and paste the link into the Play listing.
  5. App Store: confirm the export-compliance answer above; after creating the listing, put the App Store app id into the app's store links.
  6. Optional: full translated descriptions and release notes for the five other languages.
